# PR

## 규칙
- 작업 브랜치의 PR은 `develop`으로 올린다. `main`으로 바로 올리지 않는다([branching](branching.md)).
- AI 작성자 표시를 넣지 않는다. 제목과 본문 모두 해당한다. 자세한 것은 [forbidden](../forbidden.md).

## 저장소에서 확인되는 것
- PR은 머지 커밋(`Merge pull request #N …`)으로 머지되어 왔다.

## 미정
- 제목·본문 형식, 리뷰 규칙
- `develop` → `main` PR의 때와 방법
