# 다국어

## 규칙
- 화면 문구는 `src/shared/i18n/en.ts`가 기준이다. `ko.ts`는 `Dict` 타입이라 키가 빠지면 `yarn typecheck`가 실패한다. 새 문구는 두 파일에 함께 더한다.
- 화면에서는 `useI18n()`의 `t`로 문구를 꺼낸다.
- 트레이와 macOS 메뉴 문구는 Rust `src-tauri/src/app/i18n.rs`에 따로 있다. 화면 사전과 공유하지 않는다.
- `system` 선택은 OS 언어가 `ko`로 시작하면 한국어, 아니면 영어다. 프런트(`resolveLocale`)와 Rust(`i18n::resolve`)가 같은 규칙을 쓴다.
- 언어 이름(한국어, English)은 각자 자기 언어로 쓴다.
